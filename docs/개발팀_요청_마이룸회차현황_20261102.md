# [한자어] 마이룸 회차별 현황 · 이어하기 — 요청 및 답변 (2026-11-02)

안녕하세요. 지난번 이어하기 버튼 요청에 주신 질문에 답변드리고, 마이룸에 필요한 정보를 **한 번에 받을 수 있는 기능**을 새로 만들었습니다.
(테스트 서버·실서버 모두 준비되어 있습니다.)

---

## 1. 주신 질문 답변

**① 회차별 한자 — 별도 API 필요 없습니다.**
아래 2번 '회차별 현황'에 회차 한자(`main_char`)와 훈음(`main_hun`)을 함께 보내 드립니다.

**② 목록에서 빠지는 경우**
- 그 회차의 **결과 화면까지 끝까지** 갔을 때 ('남은 어휘 재도전'도 결과 화면까지 가면 빠짐)
- 학생이 이어하기 안내에서 **'처음부터'** 를 골랐을 때
- 마지막으로 한 지 **30일**이 지났을 때

**③ '남은 어휘 재도전' 중 멈춘 경우(`completed=true`)도 이어하기가 됩니다.**
`training_mode: "retry"` + `resume: true` 로 들어오시면 멈춘 곳부터 이어집니다. 훈련 중 멈춤(`completed=false`)도 마찬가지입니다.

**④ 버튼 조건 — 정리하신 내용이 맞습니다.**

| 버튼 | 조건 (아래 2번 응답 기준) |
|---|---|
| [재도전] | `completed=true` 이고 `resume=null` 이고 `can_retry=true` |
| [이어하기] | `status="in_progress"` (훈련 중 멈춤) |
| [재도전] [이어하기] | `status="retry_paused"` (훈련완료 후 '남은 어휘 재도전' 중 멈춤) |

- 모든 어휘를 획득한 회차는 재도전할 수 없습니다(`can_retry=false`).

**⑤ 마이룸 하단 회차 범위** — 훈련완료 회차와 이어하기 회차 중 **가장 큰 회차까지** 보여 주시면 됩니다.
2번 응답에는 훈련완료했거나 하다 만 회차만 들어 있으니, 응답 그대로 쓰셔도 됩니다.

**⑥ '남은 어휘 재도전'의 인출 단계에서 일부 어휘만 보이는 것 — 의도된 동작입니다.**
처음부터 보이는 어휘는 이미 **획득한 어휘**(인출 + 강화까지 통과, 금색 칩)입니다.
강화에서 뜻을 못 맞힌 어휘는 아직 획득하지 않은 어휘라, 재도전 때 다시 떠올려서 찾아야 하므로 숨겨져 있습니다.

## 2. 회차별 현황 받기 (새 기능)

학생 마이룸에서 **획득 어휘 / 미획득 어휘 수, 재도전 횟수, 회차 한자**를 보고 재도전 여부를 정할 수 있도록, 회차별 정보를 한 번에 보내 드립니다.

**요청**

```
POST https://fokuojmzhttxfkmiutmf.supabase.co/functions/v1/wordsense-progress
Content-Type: application/json

{ "action": "rounds", "user_no": 88660, "training_level": "elementary", "training_area": "science" }
```

| 값 | 내용 |
|---|---|
| `action` | `"rounds"` (필수) |
| `user_no` | 학생 회원번호 (필수) |
| `training_level` | `elementary`(초등) / `middle`(중등) |
| `training_area` | `biology` / `society` / `history` / `science` / `culture` / `economy` |

- 테스트 서버: `https://xzxgsqpvtckxgvipchsy.supabase.co/functions/v1/wordsense-progress`
- 입장권(st)은 필요 없습니다.

**응답** (회차 순서)

```json
{
  "success": true,
  "training_level": "elementary",
  "training_area": "science",
  "items": [
    {
      "training_round": 10,
      "main_char": "氣",
      "main_hun": "기운 기",
      "total_words": 49,
      "acquired": 4,
      "not_acquired": 45,
      "completed": true,
      "retry_count": 1,
      "status": "retry_paused",
      "can_retry": true,
      "resume": {
        "training_mode": "retry",
        "stage_label": "확장하기",
        "progress_text": "확장하기 4 / 38",
        "updated_at": "2026-11-02T08:07:37+00:00"
      }
    }
  ]
}
```

| 값 | 내용 |
|---|---|
| `training_round` | 회차 |
| `main_char` / `main_hun` | 회차 한자 / 훈음 (예: 氣 / 기운 기) |
| `total_words` | 회차 전체 어휘 수 |
| `acquired` | **획득 어휘** 수 (학생 화면의 '획득'과 같은 기준, 이전 훈련까지 누적) |
| `not_acquired` | **미획득 어휘** 수 |
| `completed` | 훈련완료 여부 (결과 화면까지 간 적 있음) |
| `retry_count` | **재도전 횟수** (첫 완료 이후 다시 끝까지 한 횟수) |
| `status` | `completed`(완료) / `in_progress`(훈련 중 멈춤) / `retry_paused`(재도전 중 멈춤) |
| `can_retry` | [재도전] 가능 여부 |
| `resume` | [이어하기] 정보 — 없으면 `null` |
| `resume.training_mode` | [이어하기] 누를 때 `wordsense-start`에 보낼 값 (`normal` / `retry`) |
| `resume.progress_text` | 화면에 그대로 보여 주셔도 되는 진행 문구 |

## 3. [이어하기] 버튼 — 누르면

지금 훈련 진입에 쓰시는 `wordsense-start`를 그대로 부르시되, `resume.training_mode` 값과 **`"resume": true`** 를 함께 보내 주세요.
(`normal`이면 평소처럼 `study_token` 필요, `retry`면 지금 [재도전]과 같습니다.)

## 4. 이어하기 방식 (참고 — 앱 쪽 변경)

- 훈련 화면 왼쪽 아래에 **[저장하고 끝내기]** 버튼을 넣었습니다. 누르면 **정확히 그 자리**(몇 번째 카드·문제)부터 이어집니다.
- 버튼 없이 창을 닫으면 마지막으로 시작한 **단계의 처음부터** 이어집니다. (`progress_text` 예: '강화하기 처음부터')
- 저장은 단계 시작 때와 버튼을 누를 때만 하므로 서버 부담은 거의 없습니다.

## 5. 화면 예시 (제안)

```
과학 10회차  氣 기운 기  획득 4 / 49 (미획득 45) · 재도전 1회   [재도전] [이어하기]  확장하기 4 / 38
과학 11회차  間 사이 간  획득 2 / 20 (미획득 18) · 재도전 1회   [재도전]
```

## 6. 일정 관련

말씀하신 대로 KCP 작업이 우선이니, 이 작업은 KCP 이후에 진행하셔도 됩니다. 저희 쪽 기능은 이미 준비되어 있습니다.
(지난번 보내 드린 `action: "list"`도 계속 쓰실 수 있지만, 위 `rounds` 하나로 충분합니다.)

## 7. 불러오는 시점 (부탁)

회차별 현황은 마이룸에서 **해당 과목 탭을 열 때 그 과목만 한 번** 불러와 주세요.
- 예) 생물 탭을 열면 생물만, 역사 탭으로 바꾸면 그때 역사만
- 이미 불러온 탭으로 다시 돌아올 때는, 화면을 새로 열기 전까지 받아 둔 내용을 그대로 써 주시면 됩니다.

학생 수가 많아져도 서버 부담이 커지지 않도록 하기 위한 부탁입니다.

문의는 편하게 주세요. 감사합니다.
