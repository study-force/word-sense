# [한자어] 이어하기 · 복습 · 마이룸 회차별 현황 — 답변 및 요청 (2026-11-02)

안녕하세요. 지난번 이어하기 관련 질문(1차·2차)에 답변드리고, 바뀐 내용과 마이룸에 필요한 정보를 **한 번에 받을 수 있는 기능**을 정리했습니다.
일정은 말씀하신 대로 **KCP 작업 이후**에 진행하셔도 됩니다. 저희 쪽 기능은 테스트 서버에 준비되어 있습니다.

---

## 1. 바뀐 점 — 훈련완료(엔드데이트) 시점

**훈련완료 API(엔드데이트)를 '결과 화면이 뜰 때'가 아니라, 학생이 결과 화면에서 [나의 훈사전]에 들어갈 때 보냅니다.**

결과 화면에서 '남은 어휘 재도전'을 하다가 멈춘 학생은 아직 훈사전도, 결과 기록도 보지 않았기 때문에 훈련이 끝났다고 보기 어렵습니다.
그래서 이런 경우에는 엔드데이트를 보내지 않고, **달력 ▶로 같은 회차가 다시 열려 멈춘 곳부터 이어지게** 했습니다.

| 학생이 결과 화면에서 | 훈련완료 API(엔드데이트) | 다음에 달력 ▶를 누르면 |
|---|---|---|
| [나의 훈사전 보기] | ✅ 훈사전에 들어가는 순간 | 다음 회차 |
| [남은 어휘 재도전] → 끝까지 → [나의 훈사전 보기] | ✅ 그때 | 다음 회차 |
| [남은 어휘 재도전] 중에 멈춤 | ❌ 보내지 않음 | **같은 회차 — 멈춘 곳부터 이어짐** |
| 결과만 보고 창을 닫음 | ❌ 보내지 않음 | 같은 회차 (이미 획득한 어휘는 그대로, 남은 어휘만) |

- 학원 쪽에서 **고치실 것은 없습니다.** 지금처럼 '훈련완료 API를 받지 않은 회차는 같은 `training_round`로 다시 보내기'만 해 주시면 됩니다.
- 훈련 기록(획득 어휘 등)은 결과 화면에서 저희 쪽에 바로 저장되므로 사라지지 않습니다.

## 2. 주신 질문 답변

**① 회차별 한자 — 별도 API 필요 없습니다.**
아래 3번 '회차별 현황'에 회차 한자(`main_char`)와 훈음(`main_hun`)을 함께 보내 드립니다.
(저희가 콘텐츠를 고쳐도 늘 최신 한자가 가도록, 학원 쪽에 따로 저장하지 않는 방식입니다.)

**② 이어하기 기록이 없어지는 경우**
- 그 회차의 **결과 화면까지** 갔을 때 (이어할 곳이 없어짐)
- 마지막으로 한 지 **30일**이 지났을 때

**③ 버튼 — [이어하기]가 [재도전]을 대신합니다.**
끊긴 기록이 있으면 [재도전] 대신 **[이어하기]** 를 보여 주세요. [이어하기]와 [재도전]이 같이 나올 일은 없습니다.
(새로 추가하는 **[복습]** 은 이와 별개로 옆에 함께 나올 수 있습니다 — 8번 참고)

| 버튼 | 조건 (3번 응답 기준) |
|---|---|
| [이어하기] | `resume`이 있음 (끊긴 기록 있음) |
| [재도전] | `completed=true` 이고 `resume=null` 이고 `can_retry=true` |
| [복습] | `can_review=true` (8번) |
| (없음) | 그 외 — 모든 어휘를 획득한 회차는 재도전 불가(`can_retry=false`) |

**④ [이어하기] 노출 기간**
- `status="in_progress"`(훈련완료 전) — **기존 훈련기간 안에서만** 노출해 주시면 됩니다. 1번의 '남은 어휘 재도전 중 멈춤'도 여기에 해당합니다(엔드데이트를 보내지 않았으므로).
- `status="retry_paused"`(훈련완료 후 [재도전]으로 하다 멈춤) — **[재도전] 버튼과 같은 기간**으로 보여 주시면 됩니다. 이 경우 [재도전] 자리에 [이어하기]가 나오는 것뿐이라 기간 계산을 따로 하실 필요가 없습니다.

**⑤ 마이룸 하단 회차 범위** — 훈련완료 회차와 이어하기 회차 중 **가장 큰 회차까지** 보여 주시면 됩니다.
3번 응답에는 훈련한 회차와 하다 만 회차만 들어 있으니, 응답 그대로 쓰셔도 됩니다.

**⑥ '남은 어휘 재도전'의 인출 단계에서 일부 어휘만 보이는 것 — 의도된 동작입니다.**
처음부터 보이는 어휘는 이미 **획득한 어휘**(인출 + 강화까지 통과, 금색 칩)입니다.
강화에서 뜻을 못 맞힌 어휘는 아직 획득하지 않은 어휘라, 재도전 때 다시 떠올려서 찾아야 하므로 숨겨져 있습니다.

## 3. 회차별 현황 받기 (새 기능)

학생이 마이룸에서 **회차 한자, 획득 / 미획득 어휘 수, 재도전 횟수**를 보고 재도전 여부를 정할 수 있도록, 회차별 정보를 한 번에 보내 드립니다.

**요청**

```
POST https://fokuojmzhttxfkmiutmf.supabase.co/functions/v1/wordsense-progress
Content-Type: application/json

{ "action": "rounds", "user_no": 88660, "training_level": "elementary", "training_area": "science" }
```

| 값 | 내용 |
|---|---|
| `action` | `"rounds"` (필수) |
| `user_no` | 학생 회원번호 (필수) |
| `training_level` | `elementary`(초등) / `middle`(중등) |
| `training_area` | `biology` / `society` / `history` / `science` / `culture` / `economy` |

- 테스트 서버: `https://xzxgsqpvtckxgvipchsy.supabase.co/functions/v1/wordsense-progress`
- 입장권(st)은 필요 없습니다.

**응답** (회차 순서)

```json
{
  "success": true,
  "training_level": "elementary",
  "training_area": "science",
  "items": [
    {
      "training_round": 10,
      "main_char": "氣",
      "main_hun": "기운 기",
      "total_words": 49,
      "acquired": 4,
      "not_acquired": 45,
      "completed": false,
      "retry_count": 0,
      "status": "in_progress",
      "can_retry": false,
      "can_review": false,
      "review_words": 0,
      "resume": {
        "training_mode": "normal",
        "stage_label": "확장하기",
        "progress_text": "확장하기 4 / 38",
        "updated_at": "2026-11-02T08:07:37+00:00"
      }
    }
  ]
}
```

| 값 | 내용 |
|---|---|
| `training_round` | 회차 |
| `main_char` / `main_hun` | 회차 한자 / 훈음 (예: 氣 / 기운 기) |
| `total_words` | 회차 전체 어휘 수 |
| `acquired` | **획득 어휘** 수 (학생 화면의 '획득'과 같은 기준, 이전 훈련까지 누적) |
| `not_acquired` | **미획득 어휘** 수 |
| `completed` | 훈련완료 — 훈련완료 API(엔드데이트)를 보낸 회차 |
| `retry_count` | **재도전 횟수** (첫 훈련 이후 다시 끝까지 한 횟수) |
| `status` | `completed`(완료) / `in_progress`(훈련완료 전 — 달력 ▶로 같은 회차) / `retry_paused`(훈련완료 후 [재도전]으로 하다 멈춤) |
| `can_retry` | [재도전] 가능 여부 |
| `can_review` | [복습] 가능 여부 — 훈련완료 회차에 획득 어휘가 1개 이상 (8번) |
| `review_words` | 복습할 어휘 수 (= 획득 어휘 수) |
| `resume` | [이어하기] 정보 — 끊긴 기록이 없으면 `null` |
| `resume.training_mode` | [이어하기] 누를 때 `wordsense-start`에 보낼 값 (`normal` / `retry`) |
| `resume.progress_text` | 화면에 그대로 보여 주셔도 되는 진행 문구 |

## 4. [이어하기] 버튼 — 누르면

지금 훈련 진입에 쓰시는 `wordsense-start`를 그대로 부르시되, `resume.training_mode` 값을 보내 주세요.
- `normal` → 평소 진입과 같습니다 (`study_token` 필요). 달력 ▶와 같은 입장입니다.
- `retry` → 지금 [재도전]과 같습니다.
- 이어하기 기록이 있으면 한자어 앱이 **묻지 않고 바로 멈춘 곳부터** 이어 갑니다. (`resume: true`는 보내셔도 되고 안 보내셔도 됩니다.)

## 5. 이어하기 방식 (참고 — 앱 쪽)

- 훈련 화면 왼쪽 아래에 **[저장하고 끝내기]** 버튼이 있습니다. 누르면 **정확히 그 자리**(몇 번째 카드·문제)부터 이어집니다.
- 버튼 없이 창을 닫으면 마지막으로 시작한 **단계의 처음부터** 이어집니다. (`progress_text` 예: '강화하기 처음부터')
- 저장은 단계 시작 때와 버튼을 누를 때만 하므로 서버 부담은 거의 없습니다.

## 6. 화면 예시 (제안)

```
과학 10회차  氣 기운 기  획득 4 / 49 (미획득 45)              [이어하기]  확장하기 4 / 38
과학 11회차  間 사이 간  획득 2 / 20 (미획득 18) · 재도전 1회   [재도전 18]  [복습 2]
과학 12회차  變 변할 변  획득 16 / 16 (모두 획득)               [복습 16]
```
- 버튼에 개수를 함께 적어 주시면 학생이 무엇을 하는 버튼인지 바로 알 수 있습니다. (재도전 = 미획득 수, 복습 = 획득 수)

## 7. 불러오는 시점 (부탁)

회차별 현황은 마이룸에서 **해당 과목 탭을 열 때 그 과목만 한 번** 불러와 주세요.
- 예) 생물 탭을 열면 생물만, 역사 탭으로 바꾸면 그때 역사만
- 이미 불러온 탭으로 다시 돌아올 때는, 화면을 새로 열기 전까지 받아 둔 내용을 그대로 써 주시면 됩니다.

학생 수가 많아져도 서버 부담이 커지지 않도록 하기 위한 부탁입니다.

## 8. [복습] 버튼 (새로 추가)

이미 **획득한 어휘**를 잊었거나 헷갈렸을 때 다시 떠올릴 수 있도록 **[복습]** 을 추가하려고 합니다.
특히 5회차마다 보는 실력 점검 전에 복습하고 들어가면 도움이 됩니다.

**복습 내용**
- 그 회차의 **획득 어휘만** 확장하기 카드로 다시 봅니다. (미획득 어휘는 나오지 않음 — 미획득은 [재도전]에서)
- 횟수 제한 없음
- 획득 수·랭킹·훈련완료(엔드데이트)에는 **영향이 없습니다.** 복습만으로는 진도가 나가지 않습니다.

**노출 조건**
- 3번 응답의 `can_review=true` (훈련완료 회차 + 획득 어휘 1개 이상)
- 그리고 **결제 기간 안**일 때만 보여 주세요. (결제 기간은 학원 시스템에서만 알 수 있어서 부탁드립니다)
- [이어하기]·[재도전]과 함께 옆에 나와도 됩니다.

**누르면** — `wordsense-start`를 그대로 부르시되 **`training_mode: "review"`** 로 보내 주세요. (`study_token` 필요 없음, 훈련완료 API 호출 없음 — [재도전]과 같은 방식)

```json
{ "training_mode": "review", "user_no": 88660, "user_name": "홍길동", "payment_fn": "...",
  "training_level": "elementary", "training_area": "science", "training_round": 11 }
```

- 저희 서버에서도 **훈련완료(엔드데이트)를 받은 회차만** 복습을 열어 줍니다. 훈련하지 않은 회차는 요청이 와도 열리지 않습니다.
- `review` 입장과 복습 화면은 **저희 쪽에서 준비 중**이며, 이번 일정(KCP 이후)에 맞춰 테스트 서버에 먼저 열고 말씀드리겠습니다. 버튼 자리와 조건만 미리 고려해 주시면 됩니다.

※ 1번(엔드데이트 시점)과 3번(회차별 현황)은 현재 **테스트 서버**에 반영되어 있습니다. 실서버는 확인 후 반영하고 다시 말씀드리겠습니다.
(지난번 보내 드린 `action: "list"`도 계속 쓰실 수 있지만, `rounds` 하나로 충분합니다.)
