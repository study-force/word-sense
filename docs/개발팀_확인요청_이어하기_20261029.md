# [훈감각] 훈련 이어하기 — 확인 요청 (2026-10-29)

안녕하세요. 훈감각 훈련에 **이어하기** 기능을 넣었습니다(테스트 서버·실서버 반영 완료).
학원 쪽에서 **새로 만드실 것은 없고**, 지금 연동이 아래처럼 동작하는지만 확인 부탁드립니다.

---

## 1. 추가된 기능 (참고)

- 학생이 훈련 도중(인출·확장·다시 인출·강화 어느 단계든) 창을 닫아도, **다시 들어오면 하던 지점부터** 이어서 할 수 있습니다.
  - 예) 인출에서 100개 중 50개를 찾고 닫음 → 다시 들어오면 50개가 붙은 상태에서 이어서
- 진행 상황은 저희 서버에 **회원번호 + 과정 + 영역 + 회차** 기준으로 저장합니다.
  → 학원에서 **새 입장권**으로 다시 열어도, **다른 기기·브라우저**에서 열어도 이어집니다.
- 다시 들어오면 학생에게 **"이어서 하기 / 처음부터"** 를 물어봅니다.
- 회차를 끝까지 마치면(결과 화면) 저장해 둔 진행 상황은 지웁니다.

## 2. 확인 부탁드릴 것

### ① 도중에 닫은 회차 — 다음 입장 때 같은 회차 번호를 보내 주시는지

- 학생이 끝까지 하지 않고 창을 닫으면, 저희는 **훈련완료 API를 호출하지 않습니다**(완료 API는 결과 화면에 닿았을 때만 호출).
- 이때 학원 쪽에서는 그 회차를 **아직 안 끝난 회차**로 보고, 다음 입장 때 **같은 `training_round`** 를 보내 주시는지 확인 부탁드립니다.
  - 같은 회차 번호가 와야 이어하기가 동작합니다.
  - 혹시 입장만 해도 다음 회차로 넘어가는 구조라면 알려 주세요.

### ② 같은 날 다시 들어오는 것이 가능한지

- 하루에 들어올 수 있는 횟수 제한이 있는지, 그리고 **도중에 닫은 뒤 같은 날 다시 입장**이 가능한지 확인 부탁드립니다.
  - 입장이 막혀 있으면 다음 날에만 이어서 할 수 있습니다.

### ③ 훈련 창은 팝업(`window.open`)으로 열어 주시면 좋습니다 (참고)

- 훈련 마지막 화면의 **[끝내기]** 를 누르면 창이 닫히도록 바꿨습니다.
- 브라우저는 스크립트(`window.open`)로 연 창만 닫을 수 있어서, 다른 방식(링크 새 탭 등)으로 열면 닫히지 않고 "이 창을 닫아 주세요" 안내가 뜹니다.
- 지금 여시는 방식을 알려 주시면 맞춰 보겠습니다.

## 3. 변경 없는 것

- 진입 API(`wordsense-start`)·훈련완료 API는 **그대로**입니다. 보내 주시는 값도 그대로입니다.

문의는 편하게 주세요. 감사합니다.
