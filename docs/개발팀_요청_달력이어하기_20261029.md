# [훈감각] 학원 달력 아래 목록에 [이어하기] 버튼 추가 — 요청 (2026-10-29)

안녕하세요. 훈련 **이어하기**와 관련해 학원 달력 화면에 버튼 하나를 부탁드립니다.

---

## 1. 배경

- 학생이 훈련을 하다가 창을 닫으면, 저희 서버에 **하던 지점**이 저장됩니다(인출·확장·다시 인출·강화 모두).
- 결과 화면까지 마친 뒤 **'남은 어휘 재도전'** 을 하다가 닫는 경우도 있습니다.
  - 이 회차는 이미 학원에 **완료로 보고**되어서, 달력에서 들어가면 **다음 회차**가 열립니다. 이건 지금 그대로가 맞습니다.
  - 다만 학생은 하던 재도전이 사라졌다고 느낄 수 있습니다.
- 그래서 **하다 만 회차를 달력 아래 목록에서 보여 주고, [이어하기] 버튼으로 바로 이어서** 할 수 있게 하려고 합니다.

## 2. 정리 — 달력 동작

| 학생이 누르는 것 | 열리는 회차 |
|---|---|
| 달력(평소 진입) | **항상 오늘 진행할 회차** (지금과 같음) |
| 달력 아래 목록의 [재도전] | 그 회차를 처음부터 재훈련 (지금과 같음) |
| 달력 아래 목록의 **[이어하기]** (새로) | 그 회차를 **멈춘 지점부터** 이어서 |

## 3. 하다 만 회차 목록 받기 (새로 추가된 기능)

**요청**

```
POST https://fokuojmzhttxfkmiutmf.supabase.co/functions/v1/wordsense-progress
Content-Type: application/json

{ "action": "list", "user_no": 88660, "training_level": "elementary" }
```

| 값 | 내용 |
|---|---|
| `action` | `"list"` (필수) |
| `user_no` | 학생 회원번호 (필수) |
| `training_level` | `elementary`(초등) / `middle`(중등) — 없으면 둘 다 |

- 테스트 서버: `https://xzxgsqpvtckxgvipchsy.supabase.co/functions/v1/wordsense-progress`
- 입장권(st)은 필요 없습니다.

**응답** (최근에 한 순서)

```json
{
  "success": true,
  "items": [
    {
      "training_level": "elementary",
      "training_area": "science",
      "training_round": 10,
      "completed": true,
      "training_mode": "retry",
      "stage": "fill",
      "stage_label": "강화하기",
      "progress_text": "강화하기 7 / 20",
      "updated_at": "2026-10-29T05:53:37+00:00"
    }
  ]
}
```

| 값 | 내용 |
|---|---|
| `training_level` / `training_area` / `training_round` | 하다 만 회차 (훈련 진입 때 쓰시는 값과 같은 형식) |
| `completed` | `true` = 결과 화면까지 마친 뒤 '남은 어휘 재도전' 중 멈춤 / `false` = 결과 화면 전에 멈춤 |
| `training_mode` | [이어하기]를 누를 때 `wordsense-start`에 보낼 값 (`retry` 또는 `normal`) |
| `progress_text` | 화면에 그대로 보여 주셔도 되는 진행 문구 (예: '강화하기 7 / 20') |
| `updated_at` | 마지막으로 한 시각 |

- 목록이 비어 있으면(`items: []`) 하다 만 회차가 없는 것입니다.
- 회차를 끝까지 마치면 목록에서 저절로 빠집니다. 30일이 지난 것도 빠집니다.

## 4. [이어하기] 버튼 — 누르면

지금 훈련 진입에 쓰시는 **`wordsense-start`를 그대로** 부르시되, 목록에서 받은 값과 **`"resume": true`** 를 함께 보내 주세요.

```json
{
  "user_no": 88660,
  "user_name": "홍길동",
  "payment_fn": "...",
  "training_level": "elementary",
  "training_area": "science",
  "training_round": 10,
  "training_mode": "retry",
  "resume": true
}
```

- `training_mode`는 목록의 값 그대로 보내 주세요.
  - `retry` → 지금 [재도전] 버튼과 같습니다 (`study_token` 필요 없음, 학원 완료 API 다시 안 부름).
  - `normal` → 평소 진입과 같습니다 (`study_token` 필요).
- `resume: true` 가 있으면 학생에게 "이어서 할까요?"를 묻지 않고 **바로 멈춘 지점부터** 이어집니다.
  (없으면 지금처럼 [재도전]으로 들어온 학생에게 "이어서 하기 / 처음부터"를 물어봅니다.)
- 응답(`redirectUrl`)은 지금과 같이 열어 주시면 됩니다.
