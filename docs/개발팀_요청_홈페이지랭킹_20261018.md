# [훈감각] 홈페이지 랭킹판 넣기 요청 (2026-10-18)

안녕하세요. 훈감각 어휘 훈련의 **랭킹판**을 학원 홈페이지(학생 로그인 화면)에 넣어 주셨으면 합니다.
랭킹판은 저희 쪽에서 만들어 운영하는 페이지라, 홈페이지에는 **주소 한 줄(iframe)**만 넣어 주시면 됩니다.
내용·디자인을 고칠 때도 홈페이지는 다시 손대지 않아도 됩니다.

---

## 1. 넣을 주소

```
https://word.sfcenter.co.kr/ranking.html?academy={학원번호}&level={과정}&me={회원번호}&st={입장권}
```

| 붙이는 값 | 내용 | 없으면 |
|---|---|---|
| `academy` | 학원번호 (훈련 진입 때 보내 주시는 `academy_no`와 같은 값) | '우리학원' 보기 버튼이 꺼짐 |
| `level` | `초등` 또는 `중등` | '전체'로 열림 (화면에서 바꿀 수 있음) |
| `me` | 회원번호 (`user_no`) | '나' 표시·내 순위가 안 나옴 |
| `st` | **입장권** — 아래 2번 참고 | 내 이름도 가려서 나옴 (예: 홍*동) |

- 테스트 서버는 `https://word.sfos.kr/ranking.html?...` 로 같은 방식입니다.
- 예) `https://word.sfcenter.co.kr/ranking.html?academy=1904&level=초등&me=88660&st=0d5c...`

## 2. 입장권(st) — 새로 부탁드리는 부분

랭킹판은 **본인 이름만 전체로**, 다른 친구 이름은 가운데를 가려서(홍*동) 보여 줍니다.
주소의 회원번호만 바꿔서 남의 실명을 볼 수 없도록, **본인 확인은 입장권으로** 합니다.

- 입장권 = 학생이 훈련에 들어갈 때 `wordsense-start`가 돌려주는 주소(`redirectUrl` / `Location`)의 **`st=` 뒤 값**입니다.
  ```
  https://word.sfcenter.co.kr/word-sense.html?st=0d5c1f2a-....   ← 이 값
  ```
- 학생별로 **가장 최근 입장권**을 기억해 두셨다가 랭킹 주소에 붙여 주세요.
- 입장권은 **훈련에 들어간 뒤 하루 동안** 이름 확인에 쓰입니다. 하루가 지났거나 없으면 `st`를 빼 주셔도 됩니다.
  (그럴 때는 랭킹은 그대로 보이고, 내 이름만 가려진 채 '(나)' 표시가 붙습니다.)

## 3. 넣는 방법 (예시)

```html
<iframe src="https://word.sfcenter.co.kr/ranking.html?academy=1904&level=초등&me=88660&st=0d5c..."
        style="width:100%; max-width:960px; height:900px; border:0;"
        title="훈감각 어휘 랭킹"></iframe>
```

- 너비는 화면에 맞춰 늘어나고 줄어듭니다. 휴대폰 화면에서는 두 판이 위아래로 쌓입니다.
- 높이는 900px 정도면 충분합니다(안에서 스크롤됨). 새 창 링크로 여셔도 됩니다.

## 4. 화면 구성 (참고)

- **오늘의 랭킹**: 오늘 새로 익힌 어휘 수 순위 (학생마다 '생물 9 · 역사 3'처럼 영역 내역)
- **명예의 전당 👑** (영역별): 'N회차까지 누적 만점자' — 1회차부터 빠짐없이 모든 어휘를 모은 학생, 최근 달성 순
  - 처음 열면 그 학생이 하고 있는 회차 기준, ◀ ▶ 로 다른 회차도 볼 수 있음
- 위쪽 버튼으로 [전체 / 초등 / 중등] × [전체 / 우리학원] 선택

## 5. 확인 부탁드릴 것

1. 학생별 최근 입장권(`st`)을 기억해 두는 것이 가능한지
2. 랭킹판을 넣을 위치(학생 메인 화면 / 별도 메뉴)와 예정 일정

문의는 편하게 주세요. 감사합니다.
