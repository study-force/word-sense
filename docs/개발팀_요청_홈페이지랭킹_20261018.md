# [훈감각] 홈페이지 랭킹판 · 선생님 결과지 · 무료체험 연동 (2026-10-18, 10/22 추가)

안녕하세요. 세 가지를 부탁드립니다.

- **A. 랭킹판** — 학원 홈페이지(학생 로그인 화면)에 넣기 (1~5번)
- **B. 선생님 결과지** — 학원 관리 화면에서 선생님이 학생의 훈련결과를 열 수 있게 연결 (6~9번)
- **C. 한자 무료체험** — 센터 메인 [무료체험] 버튼, [전체훈련 체험] 단계별 진입 (10~12번)

---

## A. 랭킹판

훈감각 어휘 훈련의 **랭킹판**을 학원 홈페이지(학생 로그인 화면)에 넣어 주셨으면 합니다.
랭킹판은 저희 쪽에서 만들어 운영하는 페이지라, 홈페이지에는 **주소 한 줄**(iframe)만 넣어 주시면 됩니다.
내용·디자인을 고칠 때도 홈페이지는 다시 손대지 않아도 됩니다.

---

## 1. 넣을 주소

```
https://word.sfcenter.co.kr/ranking.html?academy={학원번호}&level={과정}&me={회원번호}&st={입장권}
```

| 붙이는 값 | 내용 | 없으면 |
|---|---|---|
| `academy` | 학원번호 (훈련 진입 때 보내 주시는 `academy_no`와 같은 값) | '우리학원' 보기 버튼이 꺼짐 |
| `level` | `초등` 또는 `중등` | '전체'로 열림 (화면에서 바꿀 수 있음) |
| `me` | 회원번호 (`user_no`) | '나' 표시·내 순위가 안 나옴 |
| `st` | **입장권** — 아래 2번 참고 | 내 이름도 가려서 나옴 (예: 홍*동) |

- 테스트 서버는 `https://word.sfos.kr/ranking.html?...` 로 같은 방식입니다.
- 예) `https://word.sfcenter.co.kr/ranking.html?academy=1904&level=초등&me=88660&st=0d5c...`

## 2. 입장권(st) — 새로 부탁드리는 부분

랭킹판은 **본인 이름만 전체로**, 다른 친구 이름은 가운데를 가려서(홍*동) 보여 줍니다.
주소의 회원번호만 바꿔서 남의 실명을 볼 수 없도록, **본인 확인은 입장권으로** 합니다.

- 입장권 = 학생이 훈련에 들어갈 때 `wordsense-start`가 돌려주는 주소(`redirectUrl` / `Location`)의 **`st=` 뒤 값**입니다.
  ```
  https://word.sfcenter.co.kr/word-sense.html?st=0d5c1f2a-....   ← 이 값
  ```
- 학생별로 **가장 최근 입장권**을 기억해 두셨다가 랭킹 주소에 붙여 주세요.
- 입장권은 **훈련에 들어간 뒤 하루 동안** 이름 확인에 쓰입니다. 하루가 지났거나 없으면 `st`를 빼 주셔도 됩니다.
  (그럴 때는 랭킹은 그대로 보이고, 내 이름만 가려진 채 '(나)' 표시가 붙습니다.)

## 3. 넣는 방법 (예시)

```html
<iframe src="https://word.sfcenter.co.kr/ranking.html?academy=1904&level=초등&me=88660&st=0d5c..."
        style="width:100%; max-width:960px; height:900px; border:0;"
        title="훈감각 어휘 랭킹"></iframe>
```

- 너비는 화면에 맞춰 늘어나고 줄어듭니다. 휴대폰 화면에서는 두 판이 위아래로 쌓입니다.
- 높이는 900px 정도면 충분합니다(안에서 스크롤됨). 새 창 링크로 여셔도 됩니다.

## 4. 화면 구성 (참고)

- **오늘의 랭킹**: 오늘 새로 익힌 어휘 수 순위 (학생마다 '생물 9 · 역사 3'처럼 영역 내역)
- **명예의 전당 👑** (영역별): 'N회차까지 누적 만점자' — 1회차부터 빠짐없이 모든 어휘를 모은 학생, 최근 달성 순
  - 처음 열면 그 학생이 하고 있는 회차 기준, ◀ ▶ 로 다른 회차도 볼 수 있음
- 위쪽 버튼으로 [전체 / 초등 / 중등] × [전체 / 우리학원] 선택

## 5. 확인 부탁드릴 것

1. 학생별 최근 입장권(`st`)을 기억해 두는 것이 가능한지
2. 랭킹판을 넣을 위치(학생 메인 화면 / 별도 메뉴)와 예정 일정

## B. 선생님 결과지 연결

선생님이 학원 관리 화면에서 학생을 고르면, 그 학생의 **훈감각 훈련결과(팝업, 3쪽)**가 열리도록 연결 부탁드립니다.
결과지 화면은 저희 쪽에서 만들어 운영하고, 학원 쪽에서는 **입장권을 받아 주소를 여는 것**만 해 주시면 됩니다.

## 6. 결과지 구성 (참고)

| 쪽 | 내용 |
|---|---|
| 1쪽 | 나의 훈사전 — 영역별 회차 50칸(통과 / 미통과 / 미훈련, 모은 어휘 수) |
| 2쪽 | 영역별 훈련 현황 — 영역별 습득 어휘, 통과 회차, 등급별 어휘 습득률 |
| 3쪽 | 실력 점검 결과 — 5회차마다 보는 25문항 점검의 구간별 최고 점수, 결과 구성, 회차별 정답률 |

- 화면 아래 화살표로 쪽을 넘기고, **'선택 출력'** 버튼으로 3쪽을 A4로 인쇄할 수 있습니다.

## 7. 여는 방법 — 지금 훈련 진입과 같은 방식

학생 훈련에 들어갈 때 쓰시는 **`wordsense-start`** 를 그대로 부르시되, **`training_mode: "report"`** 만 붙여 주시면 됩니다.

**요청** (선생님이 결과 보기를 누를 때마다 한 번)

```json
POST  (훈련 진입에 쓰시는 wordsense-start 주소 그대로)
{
  "training_mode": "report",
  "user_no": 88660,
  "training_level": "middle",
  "training_area": "history",
  "academy_no": 1904
}
```

| 값 | 내용 |
|---|---|
| `training_mode` | **`"report"`** (필수) |
| `user_no` | 결과를 볼 학생의 회원번호 (필수) |
| `training_level` | 누른 훈련의 과정 — `elementary`(초등) / `middle`(중등) (권장) |
| `training_area` | 누른 훈련의 영역 — `biology` / `society` / `history` / `science` / `culture` / `economy` (권장) |
| `academy_no` | 학원번호 (선택) |

- 결과 보기에는 `user_name`, `payment_fn`, `training_round`, `study_token` 이 **필요 없습니다.**
- **(10/22 추가)** 학원 화면은 훈련마다 결과 버튼이 있으니, 누른 훈련의 **`training_level`·`training_area`** 를 함께 보내 주세요.
  예) '훈감각(역사)(중등)' 결과 → `middle` + `history` / '훈감각(과학)(초등)' 결과 → `elementary` + `science`
  → 결과지가 **그 과정**으로 만들어지고, **그 영역 탭**이 먼저 열립니다. (훈련 진입 때 보내시는 값과 같습니다)
- 두 값을 안 보내면 학생이 가장 최근에 훈련한 과정, 가장 많이 진행한 영역으로 열립니다.
- 결과지 머리의 '○○학교 N학년'은 학생이 훈련에 들어올 때 보내 주신 **학제(`user_section`)·학년** 으로 표시합니다(훈련 과정과는 별개).

**응답**

```json
{
  "success": true,
  "redirectUrl": "https://word.sfcenter.co.kr/teacher-result.html?st=44678b34-....",
  "sessionId": "44678b34-...."
}
```

→ 이 **`redirectUrl`을 팝업으로 열어 주세요.**

```js
window.open(redirectUrl, 'ws_result', 'width=800,height=1150');
```

- 결과지는 창 크기에 맞춰 비율을 유지하며 커지고 작아집니다.
- 테스트 서버도 같은 방식입니다(응답 주소가 `https://word.sfos.kr/teacher-result.html?st=...`).

## 8. 입장권 안내

- 결과 보기 입장권은 **발급 후 6시간** 동안 쓸 수 있습니다. 선생님이 결과 보기를 누를 때마다 새로 받아 주시면 됩니다.
- 결과 보기 입장권으로는 **훈련을 열거나 실력 점검을 풀 수 없습니다**(결과 보기 전용).
- 결과지의 학생 이름·학원은 학생이 훈련에 들어올 때 보내 주신 정보로 표시됩니다.

## 9. 확인 부탁드릴 것 (B)

1. 결과 보기 버튼을 넣을 위치(학생 목록 / 학생 상세 등)와 예정 일정
2. 팝업 대신 새 탭으로 여는 편이 낫다면 알려 주세요 (화면은 그대로 동작합니다)

## C. 한자 무료체험 연동 (10/22 추가)

입장권이나 로그인 없이 **주소만 열면** 됩니다. 체험 기록은 저장하지 않습니다.

## 10. 센터 메인 훈련소개 — [무료체험] 버튼

| 과정 | 주소 |
|---|---|
| 초등 | `https://word.sfcenter.co.kr/word-sense.html?trial=1&level=elementary` |
| 중등 | `https://word.sfcenter.co.kr/word-sense.html?trial=1&level=middle` |

- 버튼을 누르면 위 주소를 **새 창(또는 새 탭)** 으로 열어 주세요. 훈련 화면은 전체 화면에 맞춰 커지고 작아집니다.
- 체험은 항상 **생물 1회차(生 날 생)** 로 열립니다(주소를 바꿔도 다른 회차는 열리지 않습니다).
- 처음부터 끝까지(오늘의 한자 → 인출 → 확장 → 다시 인출 → 강화 → 결과) 그대로 해 볼 수 있습니다.

## 11. [센터관리 > 전체훈련 체험] — 단계별 진입

위 주소 뒤에 **`&stage=`** 만 붙여 주시면 됩니다.

| 단계 | 붙일 값 | 동작 |
|---|---|---|
| 인출 | `&stage=retrieve` | 오늘의 한자 → **인출** → 결과 |
| 확장 | `&stage=expand` | 오늘의 한자 → **확장** → 결과 |
| 강화 | `&stage=reinforce` | 오늘의 한자 → **강화**(예시 어휘 10개) → 결과 |

예) 초등 강화 체험 → `https://word.sfcenter.co.kr/word-sense.html?trial=1&level=elementary&stage=reinforce`

- `level` 은 `elementary`(초등) / `middle`(중등), 없으면 초등입니다.
- 테스트 서버는 주소 앞부분만 `https://word.sfos.kr/` 로 바꾸시면 됩니다.

## 12. 확인 부탁드릴 것 (C)

1. 새 창 / 새 탭 중 어느 쪽으로 여실지
2. 단계별 체험 버튼 3개(인출·확장·강화)를 초등·중등 각각 두실지

문의는 편하게 주세요. 감사합니다.
